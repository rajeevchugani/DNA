Transcription: copying a gene into mRNA

DNA stays safe in the nucleus, so a working copy of one gene is made. This copy is called messenger RNA (mRNA). RNA polymerase builds it by matching RNA bases to the template strand.

    Top: coding strand. Middle: template strand. Bottom: the mRNA being built.

    When making RNA from a DNA template: A pairs with U, T pairs with A, C pairs with G, G pairs with C. RNA has no thymine (T).

    Translation: making a protein

    The code in mRNA is used to build a protein at a ribosome. Follow the mRNA from the nucleus to the finished protein.

      How tRNA works: each tRNA has an anticodon (3 bases) at one end and one specific amino acid at the other. The anticodon is complementary to a codon, so it binds to the mRNA by base pairing (A with U, G with C) using hydrogen bonds. This is how the correct amino acid is brought to the correct place in the chain.

      DNA replication: copying DNA

      Before a cell divides, it copies all of its DNA. Each strand is used as a template to build a new partner strand, so each new DNA molecule has one old strand and one new strand.

        Semi-conservative replication: each new DNA molecule contains one original (old) strand and one newly made strand. Complementary base pairing (A with T, C with G) makes the two new molecules identical to the original.

        Purines and pyrimidines

        The four bases come in two shapes. Purines (A and G) have a double ring. Pyrimidines (C, T and, in RNA, U) have a single ring. A purine always pairs with a pyrimidine, so the rungs are the same width.
